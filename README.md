### AI Jobs Market Analysis

## Description

This project analyzes the AI job market to understand job roles, salaries, required skills, experience levels, locations, and employment trends. Using Python, Pandas, NumPy, Matplotlib, Seaborn, and Power BI, the project explores the dataset and identifies useful patterns and business insights from AI-related job postings.

## Getting Started

### Dependencies

* Python 3.x
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Jupyter Notebook
* Power BI Desktop
* Windows 10/11 or compatible operating system

### Installing

* Install Python from the official Python website.
* Install the required libraries:

```bash
pip install pandas numpy matplotlib seaborn jupyter
```

* Download or clone this project.
* Place the AI Jobs dataset in the project folder.

### Executing program

* Open Jupyter Notebook.
* Load the AI Jobs dataset using Pandas.
* Perform data cleaning and preprocessing.
* Analyze job roles, salaries, skills, experience, and locations.
* Create visualizations using Matplotlib and Seaborn.
* Build an interactive dashboard using Power BI.

Example:

```python
import pandas as pd

df = pd.read_csv("ai_jobs.csv")
df.head()
```

## Help

Common issues include incorrect file paths, missing libraries, and column-name errors.

```bash
pip install pandas numpy matplotlib seaborn
```

Make sure the dataset file name and column names match the code.
